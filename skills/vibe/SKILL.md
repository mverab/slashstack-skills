# Vibe

## Purpose

Turn rough intent into a focused, scoped build direction.

## When to Use

Use before shaping a rough product or implementation idea.

## Workflow

1. Read context: open `.agents/memory/project.md` and load relevant references from `.agents/references/` before proposing any direction.
2. Define scope: list what is explicitly in-scope and what is explicitly out-of-scope.
3. Select approach: choose the simplest viable strategy given project constraints.
4. Identify the single next step: state one concrete, immediately actionable step to begin.

## Output

A scope statement containing:
- Goal: one-sentence objective
- In-scope: specific items that will be addressed
- Out-of-scope: specific items that will not be addressed
- Chosen approach: the strategy selected and why
- Single next step: the one concrete action to take first
